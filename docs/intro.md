# Giới thiệu

Chào mừng bạn đến với **TechRes Documentation** - tài liệu kỹ thuật chính thức của dự án.

## Tổng quan

TechRes Documentation được xây dựng để cung cấp cho bạn tất cả thông tin cần thiết về dự án, bao gồm:

- **Hướng dẫn sử dụng** - Các bước để bắt đầu sử dụng
- **API Reference** - Tài liệu chi tiết về các API
- **Best Practices** - Các phương pháp tốt nhất

## Bắt đầu nhanh

Bạn có thể bắt đầu bằng cách đọc qua các tài liệu sau:

1. [Cài đặt](/docs/tutorial/installation) - Hướng dẫn cài đặt
2. [Bắt đầu nhanh](/docs/tutorial/getting-started) - Các bước đầu tiên
3. [Cấu hình](/docs/tutorial/configuration) - Tùy chỉnh theo nhu cầu

## Đóng góp

Chúng tôi luôn chào đón sự đóng góp từ cộng đồng. Nếu bạn tìm thấy lỗi hoặc muốn cải thiện tài liệu, vui lòng tạo Pull Request trên GitHub.
